# T1176 - Software Extensions

- **Tactic(s):** Persistence
- **ATT&CK link:** https://attack.mitre.org/techniques/T1176/
- **Platforms:** Linux, macOS, Windows

## Summary
Adversaries may abuse software extensions to establish persistent access to victim systems.

## Status: guidance only
Software Extensions is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1176.001, T1176.002).

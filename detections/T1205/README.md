# T1205 - Traffic Signaling

- **Tactic(s):** Stealth, Persistence, Command And Control
- **ATT&CK link:** https://attack.mitre.org/techniques/T1205/
- **Platforms:** Linux, macOS, Network Devices, Windows

## Summary
Adversaries may use traffic signaling to hide open ports or other malicious functionality used for persistence or command and control.

## Status: guidance only
Traffic Signaling is a parent technique.

## How to detect it
- See T1205.001 / T1205.002 guidance.

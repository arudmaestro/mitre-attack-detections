# T1600 - Weaken Encryption

- **Tactic(s):** Defense Impairment
- **ATT&CK link:** https://attack.mitre.org/techniques/T1600/
- **Platforms:** Network Devices

## Summary
Adversaries may compromise a network device’s encryption capability in order to bypass encryption that would otherwise protect data communications.

## Status: guidance only
Weaken Encryption is a parent technique. Network device techniques run on routers, switches and firewalls; their logs (syslog, AAA, configuration archives) are not data sources of this project yet.

No sub-technique has a log-based rule either.

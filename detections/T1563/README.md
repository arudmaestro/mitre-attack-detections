# T1563 - Remote Service Session Hijacking

- **Tactic(s):** Lateral Movement
- **ATT&CK link:** https://attack.mitre.org/techniques/T1563/
- **Platforms:** Linux, macOS, Windows

## Summary
Adversaries may take control of preexisting sessions with remote services to move laterally in an environment.

## Status: guidance only
Remote Service Session Hijacking is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1563.001 is guidance.

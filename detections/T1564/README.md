# T1564 - Hide Artifacts

- **Tactic(s):** Stealth
- **ATT&CK link:** https://attack.mitre.org/techniques/T1564/
- **Platforms:** ESXi, Linux, macOS, Office Suite, Windows

## Summary
Adversaries may attempt to hide artifacts associated with their behaviors to evade detection.

## Status: guidance only
Hide Artifacts is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1564.005, .007, .010 and .012 are guidance.

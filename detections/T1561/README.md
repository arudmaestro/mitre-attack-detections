# T1561 - Disk Wipe

- **Tactic(s):** Impact
- **ATT&CK link:** https://attack.mitre.org/techniques/T1561/
- **Platforms:** Linux, macOS, Windows, Network Devices

## Summary
Adversaries may wipe or corrupt raw disk data on specific systems or in large numbers in a network to interrupt availability to system and network resources.

## Status: guidance only
Disk Wipe is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; both sub-techniques have rules.

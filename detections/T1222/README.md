# T1222 - File and Directory Permissions Modification

- **Tactic(s):** Defense Impairment
- **ATT&CK link:** https://attack.mitre.org/techniques/T1222/
- **Platforms:** ESXi, Linux, macOS, Windows

## Summary
Adversaries may modify file or directory permissions/attributes to evade access control lists (ACLs) and access protected files.

## Status: guidance only
File and Directory Permissions Modification is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1222.001 Windows; T1222.002 Linux/macOS is in the next batch).

# T1110 - Brute Force

- **Tactic(s):** Credential Access
- **ATT&CK link:** https://attack.mitre.org/techniques/T1110/
- **Platforms:** Containers, ESXi, IaaS, Identity Provider, Linux, macOS, Network Devices, Office Suite, SaaS, Windows

## Summary
Adversaries may use brute force techniques to gain access to accounts when passwords are unknown or when password hashes are obtained.

## Status: guidance only
Brute Force is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1110.001, .002, .003).

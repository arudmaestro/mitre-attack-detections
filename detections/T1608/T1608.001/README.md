# T1608.001 - Stage Capabilities: Upload Malware

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1608/001/
- **Platforms:** PRE

## Summary
Adversaries may upload malware to third-party or adversary controlled infrastructure to make it accessible during targeting.

## Status: guidance only
This is a Resource Development technique: it happens on infrastructure the adversary controls, outside your logs.

## How to detect it
- Threat intelligence for malware hosted on legitimate services (code hosting, file sharing, paste sites); the download is covered by the T1105 and T1567.003 rules.

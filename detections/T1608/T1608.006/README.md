# T1608.006 - Stage Capabilities: SEO Poisoning

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1608/006/
- **Platforms:** PRE

## Summary
Adversaries may poison mechanisms that influence search engine optimization (SEO) to further lure staged capabilities towards potential victims.

## Status: guidance only
This is a Resource Development technique: it happens on infrastructure the adversary controls, outside your logs.

## How to detect it
- Software downloaded from search results and run by users is covered by the T1204.002 rules; allowlist software sources and use an internal software portal.

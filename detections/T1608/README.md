# T1608 - Stage Capabilities

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1608/
- **Platforms:** PRE

## Summary
Adversaries may upload, install, or otherwise set up capabilities that can be used during targeting.

## Status: guidance only
Stage Capabilities is a parent technique. This is a Resource Development technique: it happens on infrastructure the adversary controls, outside your logs.

No sub-technique has a log-based rule either.

- See the sub-technique READMEs; all sub-techniques are guidance.

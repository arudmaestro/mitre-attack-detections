# T1608.005 - Stage Capabilities: Link Target

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1608/005/
- **Platforms:** PRE

## Summary
Adversaries may put in place resources that are referenced by a link that can be used during targeting.

## Status: guidance only
This is a Resource Development technique: it happens on infrastructure the adversary controls, outside your logs.

## How to detect it
- Mail and proxy URL reputation; short-link expansion in mail security; the phishing guidance in T1566.002 / T1598.003.

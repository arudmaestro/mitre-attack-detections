# T1137 - Office Application Startup

- **Tactic(s):** Persistence
- **ATT&CK link:** https://attack.mitre.org/techniques/T1137/
- **Platforms:** Windows, Office Suite

## Summary
Adversaries may leverage Microsoft Office-based applications for persistence between startups.

## Status: guidance only
Office Application Startup is a parent technique.

## How to detect it
- Use the sub-technique rules (T1137.002, .004, .006); the others are guidance.

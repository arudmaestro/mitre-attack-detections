# T1587 - Develop Capabilities

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1587/
- **Platforms:** PRE

## Summary
Adversaries may build capabilities that can be used during targeting.

## Status: guidance only
Develop Capabilities is a parent technique. This is a Resource Development technique: it happens on infrastructure or accounts the adversary controls, outside your logs.

No sub-technique has a log-based rule either.

- See the sub-technique READMEs; all sub-techniques are guidance.

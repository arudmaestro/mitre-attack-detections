# T1599 - Network Boundary Bridging

- **Tactic(s):** Defense Impairment
- **ATT&CK link:** https://attack.mitre.org/techniques/T1599/
- **Platforms:** Network Devices

## Summary
Adversaries may bridge network boundaries by compromising perimeter network devices or internal devices responsible for network segmentation.

## Status: guidance only
Network Boundary Bridging is a parent technique. Network device techniques run on routers, switches and firewalls; their logs (syslog, AAA, configuration archives) are not data sources of this project yet.

No sub-technique has a log-based rule either.

## How to detect it
- See the sub-technique READMEs; T1599.001 is guidance.

# T1213 - Data from Information Repositories

- **Tactic(s):** Collection
- **ATT&CK link:** https://attack.mitre.org/techniques/T1213/
- **Platforms:** Linux, Windows, macOS, SaaS, IaaS, Office Suite

## Summary
Adversaries may leverage information repositories to mine valuable information.

## Status: guidance only
Data from Information Repositories is a parent technique; the data lives in SaaS and server applications.

## How to detect it
- Use the sub-technique guidance and the T1213.006 database rules.

# T1505 - Server Software Component

- **Tactic(s):** Persistence
- **ATT&CK link:** https://attack.mitre.org/techniques/T1505/
- **Platforms:** Windows, Linux, macOS, Network Devices, ESXi

## Summary
Adversaries may abuse legitimate extensible development features of servers to establish persistent access to systems.

## Status: guidance only
Server Software Component is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1505.001 - .005); T1505.006 is guidance.

# T1591 - Gather Victim Org Information

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1591/
- **Platforms:** PRE

## Summary
Adversaries may gather information about the victim's organization that can be used during targeting.

## Status: guidance only
Gather Victim Org Information is a parent technique. This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

No sub-technique has a log-based rule either.

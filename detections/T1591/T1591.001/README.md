# T1591.001 - Gather Victim Org Information: Determine Physical Locations

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1591/001/
- **Platforms:** PRE

## Summary
Adversaries may gather the victim's physical location(s) that can be used during targeting.

## Status: guidance only
This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

## How to detect it
- Reduce what is exposed: review what your public websites, DNS records, job postings and employee profiles reveal, and remove what attackers do not need.
- Physical security awareness (tailgating, badge cloning) for locations named in public sources.

# T1590.003 - Gather Victim Network Information: Network Trust Dependencies

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1590/003/
- **Platforms:** PRE

## Summary
Adversaries may gather information about the victim's network trust dependencies that can be used during targeting.

## Status: guidance only
This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

## How to detect it
- Reduce what is exposed: review what your public websites, DNS records, job postings and employee profiles reveal, and remove what attackers do not need.
- Third-party access reviews: know which partners and service providers have network or account access, and monitor their sign-ins.

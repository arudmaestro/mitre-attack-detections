# T1585 - Establish Accounts

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1585/
- **Platforms:** PRE

## Summary
Adversaries may create and cultivate accounts with services that can be used during targeting.

## Status: guidance only
Establish Accounts is a parent technique. This is a Resource Development technique: it happens on infrastructure or accounts the adversary controls, outside your logs.

No sub-technique has a log-based rule either.

## How to detect it
- See the sub-technique READMEs; all sub-techniques are guidance.

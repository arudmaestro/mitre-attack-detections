# T1578 - Modify Cloud Compute Infrastructure

- **Tactic(s):** Defense Impairment
- **ATT&CK link:** https://attack.mitre.org/techniques/T1578/
- **Platforms:** IaaS

## Summary
An adversary may attempt to modify a cloud account's compute service infrastructure to evade defenses.

## Status: guidance only
Modify Cloud Compute Infrastructure is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1578.004 and T1578.005 have rules; .001 - .003 are guidance.

# T1056 - Input Capture

- **Tactic(s):** Collection, Credential Access
- **ATT&CK link:** https://attack.mitre.org/techniques/T1056/
- **Platforms:** Linux, macOS, Network Devices, Windows

## Summary
Adversaries may use methods of capturing user input to obtain credentials or collect information.

## Status: guidance only
Input Capture is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1056.001 keylogging, T1056.002 GUI input capture).

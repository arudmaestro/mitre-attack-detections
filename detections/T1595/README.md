# T1595 - Active Scanning

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1595/
- **Platforms:** PRE

## Summary
Adversaries may execute active reconnaissance scans to gather information that can be used during targeting.

## Status: guidance only
Active Scanning is a parent technique. This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

No sub-technique has a log-based rule either.

# T1098 - Account Manipulation

- **Tactic(s):** Persistence, Privilege Escalation
- **ATT&CK link:** https://attack.mitre.org/techniques/T1098/
- **Platforms:** Containers, ESXi, IaaS, Identity Provider, Linux, macOS, Network Devices, Office Suite, SaaS, Windows

## Summary
Adversaries may manipulate accounts to maintain and/or elevate access to victim systems.

## Status: guidance only
Account Manipulation is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1098.001, .003, .004, .006, .007).

# T1593 - Search Open Websites/Domains

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1593/
- **Platforms:** PRE

## Summary
Adversaries may search freely available websites and/or domains for information about victims that can be used during targeting.

## Status: guidance only
Search Open Websites/Domains is a parent technique. This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

No sub-technique has a log-based rule either.

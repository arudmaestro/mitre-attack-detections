# T1069 - Permission Groups Discovery

- **Tactic(s):** Discovery
- **ATT&CK link:** https://attack.mitre.org/techniques/T1069/
- **Platforms:** Containers, IaaS, Identity Provider, Linux, macOS, Office Suite, SaaS, Windows

## Summary
Adversaries may attempt to discover group and permission settings.

## Status: guidance only
Permission Groups Discovery is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1069.001 local groups, T1069.002 domain groups).

# T1560 - Archive Collected Data

- **Tactic(s):** Collection
- **ATT&CK link:** https://attack.mitre.org/techniques/T1560/
- **Platforms:** Linux, macOS, Windows

## Summary
An adversary may compress and/or encrypt data that is collected prior to exfiltration.

## Status: guidance only
Archive Collected Data is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1560.002 and T1560.003 are guidance.

# T1552 - Unsecured Credentials

- **Tactic(s):** Credential Access
- **ATT&CK link:** https://attack.mitre.org/techniques/T1552/
- **Platforms:** Windows, SaaS, IaaS, Linux, macOS, Containers, Network Devices, Office Suite, Identity Provider

## Summary
Adversaries may search compromised systems to find and obtain insecurely stored credentials.

## Status: guidance only
Unsecured Credentials is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1552.008 is guidance.

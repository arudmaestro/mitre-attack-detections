# T1696 - Anti-Automation Evasion

- **Tactic(s):** Stealth
- **ATT&CK link:** https://attack.mitre.org/techniques/T1696/
- **Platforms:** SaaS

## Summary
Adversaries may employ various means to evade or complete automation checks.

## Status: guidance only
Anti-Automation Evasion is a parent technique. Anti-automation checks (CAPTCHAs) protect web forms; evasion is seen in web application logs.

No sub-technique has a log-based rule either.

## How to detect it
- See the sub-technique READMEs; all sub-techniques are guidance.

# T1596.002 - Search Open Technical Databases: WHOIS

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1596/002/
- **Platforms:** PRE

## Summary
Adversaries may search public WHOIS data for information about victims that can be used during targeting.

## Status: guidance only
This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

## How to detect it
- Use registrar privacy for WHOIS and generic role mailboxes as contacts.

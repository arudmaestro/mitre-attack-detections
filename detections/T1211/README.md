# T1211 - Exploitation for Stealth

- **Tactic(s):** Stealth
- **ATT&CK link:** https://attack.mitre.org/techniques/T1211/
- **Platforms:** Linux, Windows, macOS, SaaS, IaaS

## Summary
Adversaries may exploit vulnerabilities to evade detection by hiding activity, suppressing logging, or operating within trusted or unmonitored components.

## Status: guidance only
Exploits used to evade defenses target specific security products and vulnerabilities.

## How to detect it
- Monitor security tools for crashes, stopped services and tamper alerts.
- Patch security software promptly; use EDR tamper protection.

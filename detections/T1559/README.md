# T1559 - Inter-Process Communication

- **Tactic(s):** Execution
- **ATT&CK link:** https://attack.mitre.org/techniques/T1559/
- **Platforms:** Linux, macOS, Windows

## Summary
Adversaries may abuse inter-process communication (IPC) mechanisms for local code or command execution.

## Status: guidance only
Inter-Process Communication is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1559.002 and T1559.003 are guidance.

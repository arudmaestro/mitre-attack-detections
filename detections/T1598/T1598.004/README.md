# T1598.004 - Phishing for Information: Spearphishing Voice

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1598/004/
- **Platforms:** PRE

## Summary
Adversaries may use voice communications to elicit sensitive information that can be used during targeting.

## Status: guidance only
Voice phishing for information happens over the phone.

## How to detect it
- Helpdesk verification procedures (call-back to a known number, manager approval) before password resets or MFA changes; staff awareness.

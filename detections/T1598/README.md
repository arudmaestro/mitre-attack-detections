# T1598 - Phishing for Information

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1598/
- **Platforms:** PRE

## Summary
Adversaries may send phishing messages to elicit sensitive information that can be used during targeting.

## Status: guidance only
Phishing for Information is a parent technique. Phishing for information is seen in mail, chat and phone channels, not in endpoint logs.

No sub-technique has a log-based rule either.

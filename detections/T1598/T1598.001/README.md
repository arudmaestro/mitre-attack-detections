# T1598.001 - Phishing for Information: Spearphishing Service

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1598/001/
- **Platforms:** PRE

## Summary
Adversaries may send spearphishing messages via third-party services to elicit sensitive information that can be used during targeting.

## Status: guidance only
Phishing through third-party services (social media, personal webmail, chat apps) happens outside corporate mail logs.

## How to detect it
- Staff awareness for unexpected requests on social media and chat; proxy / CASB logs for credential pages on unknown domains.

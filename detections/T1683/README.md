# T1683 - Generate Content

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1683/
- **Platforms:** PRE

## Summary
Adversaries may create or generate content to support targeting and operations.

## Status: guidance only
Generate Content is a parent technique. This is a Resource Development technique: it happens on infrastructure the adversary controls, outside your logs.

No sub-technique has a log-based rule either.

- See the sub-technique READMEs; all sub-techniques are guidance.

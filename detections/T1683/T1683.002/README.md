# T1683.002 - Generate Content: Audio-Visual Content

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1683/002/
- **Platforms:** PRE

## Summary
Adversaries may create or manipulate audio, image, and video content to support targeting and malicious operations.

## Status: guidance only
This is a Resource Development technique: it happens on infrastructure the adversary controls, outside your logs.

## How to detect it
- Deepfake audio and video are used in calls and meetings; use call-back verification for payment requests and sensitive changes, and code words for executives.

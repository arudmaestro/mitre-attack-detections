# T1683.001 - Generate Content: Written Content

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1683/001/
- **Platforms:** PRE

## Summary
Adversaries may create or tailor written materials to support targeting and malicious operations.

## Status: guidance only
This is a Resource Development technique: it happens on infrastructure the adversary controls, outside your logs.

## How to detect it
- Generated phishing text, fake profiles and documents are seen only when delivered; use the phishing guidance (T1566, T1598) and staff awareness.

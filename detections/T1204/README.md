# T1204 - User Execution

- **Tactic(s):** Execution
- **ATT&CK link:** https://attack.mitre.org/techniques/T1204/
- **Platforms:** Linux, Windows, macOS, IaaS, Containers

## Summary
An adversary may rely upon specific actions by a user in order to gain execution.

## Status: guidance only
User Execution is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1204.002, T1204.004); the others are guidance.

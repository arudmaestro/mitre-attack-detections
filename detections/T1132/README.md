# T1132 - Data Encoding

- **Tactic(s):** Command And Control
- **ATT&CK link:** https://attack.mitre.org/techniques/T1132/
- **Platforms:** ESXi, Linux, macOS, Windows

## Summary
Adversaries may encode data to make the content of command and control traffic more difficult to detect.

## Status: guidance only
Data Encoding is a parent technique for C2 encoding.

## How to detect it
- See T1132.001 / T1132.002 guidance.

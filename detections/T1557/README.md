# T1557 - Adversary-in-the-Middle

- **Tactic(s):** Credential Access, Collection
- **ATT&CK link:** https://attack.mitre.org/techniques/T1557/
- **Platforms:** Linux, macOS, Network Devices, Windows

## Summary
Adversaries may attempt to position themselves between two or more networked devices using an adversary-in-the-middle (AiTM) technique to support follow-on behaviors such as Network Sniffing, Transmitted Data Manipulation, or replay attacks (Exploitation for Credential Access).

## Status: guidance only
Adversary-in-the-Middle is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1557.001 and T1557.002 have rules; T1557.003 and T1557.004 are covered separately.

# T1592.003 - Gather Victim Host Information: Firmware

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1592/003/
- **Platforms:** PRE

## Summary
Adversaries may gather information about the victim's host firmware that can be used during targeting.

## Status: guidance only
This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

## How to detect it
- Reduce what is exposed: review what your public websites, DNS records, job postings and employee profiles reveal, and remove what attackers do not need.
- Keep firmware current; firmware versions leak through device banners and support tickets.

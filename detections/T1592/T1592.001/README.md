# T1592.001 - Gather Victim Host Information: Hardware

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1592/001/
- **Platforms:** PRE

## Summary
Adversaries may gather information about the victim's host hardware that can be used during targeting.

## Status: guidance only
This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

## How to detect it
- Reduce what is exposed: review what your public websites, DNS records, job postings and employee profiles reveal, and remove what attackers do not need.
- Hardware details often leak through job postings, procurement notices and support forums.

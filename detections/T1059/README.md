# T1059 - Command and Scripting Interpreter

- **Tactic(s):** Execution
- **ATT&CK link:** https://attack.mitre.org/techniques/T1059/
- **Platforms:** Containers, ESXi, IaaS, Identity Provider, Linux, macOS, Network Devices, Office Suite, SaaS, Windows

## Summary
Adversaries may abuse command and script interpreters to execute commands, scripts, or binaries.

## Status: guidance only
Command and Scripting Interpreter is a parent technique; each interpreter needs its own detection.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1059.001 - .007, .010, .011, .013).

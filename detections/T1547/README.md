# T1547 - Boot or Logon Autostart Execution

- **Tactic(s):** Persistence, Privilege Escalation
- **ATT&CK link:** https://attack.mitre.org/techniques/T1547/
- **Platforms:** Linux, macOS, Windows, Network Devices

## Summary
Adversaries may configure system settings to automatically execute a program during system boot or logon to maintain persistence or gain higher-level privileges on compromised systems.

## Status: guidance only
Boot or Logon Autostart Execution is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1547.007 is guidance.

# T1586.001 - Compromise Accounts: Social Media Accounts

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1586/001/
- **Platforms:** PRE

## Summary
Adversaries may compromise social media accounts that can be used during targeting.

## Status: guidance only
This is a Resource Development technique: it happens on infrastructure or accounts the adversary controls, outside your logs.

## How to detect it
- Monitor for compromised partner or employee social media accounts that start sending links or files; train staff to verify unexpected requests through another channel.

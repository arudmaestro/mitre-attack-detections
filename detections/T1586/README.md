# T1586 - Compromise Accounts

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1586/
- **Platforms:** PRE

## Summary
Adversaries may compromise accounts with services that can be used during targeting.

## Status: guidance only
Compromise Accounts is a parent technique. This is a Resource Development technique: it happens on infrastructure or accounts the adversary controls, outside your logs.

No sub-technique has a log-based rule either.

- See the sub-technique READMEs; all sub-techniques are guidance.

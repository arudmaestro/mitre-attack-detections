# T1496 - Resource Hijacking

- **Tactic(s):** Impact
- **ATT&CK link:** https://attack.mitre.org/techniques/T1496/
- **Platforms:** Windows, IaaS, Linux, macOS, Containers, SaaS

## Summary
Adversaries may leverage the resources of co-opted systems to complete resource-intensive tasks, which may impact system and/or hosted service availability.

## Status: guidance only
Resource Hijacking is a parent technique.

## How to detect it
- Use the T1496.001 and T1496.004 rules; the others are guidance.

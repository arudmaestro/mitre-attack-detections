# T1550 - Use Alternate Authentication Material

- **Tactic(s):** Lateral Movement
- **ATT&CK link:** https://attack.mitre.org/techniques/T1550/
- **Platforms:** Containers, IaaS, Identity Provider, Linux, Office Suite, SaaS, Windows

## Summary
Adversaries may use alternate authentication material, such as password hashes, Kerberos tickets, and application access tokens, in order to move laterally within an environment and bypass normal system access controls.

## Status: guidance only
Use Alternate Authentication Material is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1550.001 and T1550.004 are guidance.

# T1546 - Event Triggered Execution

- **Tactic(s):** Privilege Escalation, Persistence
- **ATT&CK link:** https://attack.mitre.org/techniques/T1546/
- **Platforms:** Linux, macOS, Windows, SaaS, IaaS, Office Suite

## Summary
Adversaries may establish persistence and/or elevate privileges using system mechanisms that trigger execution based on specific events.

## Status: guidance only
Event Triggered Execution is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1546.004, .005, .016 and .018 are guidance.

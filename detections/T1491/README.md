# T1491 - Defacement

- **Tactic(s):** Impact
- **ATT&CK link:** https://attack.mitre.org/techniques/T1491/
- **Platforms:** Windows, IaaS, Linux, macOS, ESXi

## Summary
Adversaries may modify visual content available internally or externally to an enterprise network, thus affecting the integrity of the original content.

## Status: guidance only
Defacement is a parent technique.

## How to detect it
- Use the T1491.001 rule; T1491.002 is guidance.

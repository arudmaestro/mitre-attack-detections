# T1565 - Data Manipulation

- **Tactic(s):** Impact
- **ATT&CK link:** https://attack.mitre.org/techniques/T1565/
- **Platforms:** Linux, macOS, Windows

## Summary
Adversaries may insert, delete, or manipulate data in order to influence external outcomes or hide activity, thus threatening the integrity of the data.

## Status: guidance only
Data Manipulation is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; all sub-techniques are guidance.

# T1036 - Masquerading

- **Tactic(s):** Stealth
- **ATT&CK link:** https://attack.mitre.org/techniques/T1036/
- **Platforms:** Containers, ESXi, Linux, macOS, Windows

## Summary
Adversaries may attempt to manipulate features of their artifacts to make them appear legitimate or benign to users and/or security tools.

## Status: guidance only
Masquerading is a parent technique; each method needs its own detection.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1036.002, .003, .004, .005, .006, .007, .010).

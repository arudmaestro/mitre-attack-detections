# T1574 - Hijack Execution Flow

- **Tactic(s):** Stealth, Execution
- **ATT&CK link:** https://attack.mitre.org/techniques/T1574/
- **Platforms:** Linux, macOS, Windows

## Summary
Adversaries may execute their own malicious payloads by hijacking the way operating systems run programs.

## Status: guidance only
Hijack Execution Flow is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1574.004, .005, .008, .010 and .013 are guidance.

# T1052 - Exfiltration Over Physical Medium

- **Tactic(s):** Exfiltration
- **ATT&CK link:** https://attack.mitre.org/techniques/T1052/
- **Platforms:** Linux, macOS, Windows

## Summary
Adversaries may attempt to exfiltrate data via a physical medium, such as a removable drive.

## Status: guidance only
Exfiltration over physical medium is a parent technique.

## How to detect it
- See T1052.001 guidance (USB).

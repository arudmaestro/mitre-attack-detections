# T1114 - Email Collection

- **Tactic(s):** Collection
- **ATT&CK link:** https://attack.mitre.org/techniques/T1114/
- **Platforms:** Windows, macOS, Linux, Office Suite

## Summary
Adversaries may target user email to collect sensitive information.

## Status: guidance only
Email Collection is a parent technique.

## How to detect it
- See T1114.001 (local .pst/.ost rule). Remote and forwarding-rule collection are separate sub-techniques.

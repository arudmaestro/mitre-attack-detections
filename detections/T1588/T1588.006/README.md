# T1588.006 - Obtain Capabilities: Vulnerabilities

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1588/006/
- **Platforms:** PRE

## Summary
Adversaries may acquire information about vulnerabilities that can be used during targeting.

## Status: guidance only
This is a Resource Development technique: it happens on infrastructure or accounts the adversary controls, outside your logs.

## How to detect it
- Vulnerability management with external attack surface scanning, so you find exposed vulnerable services before attackers do.

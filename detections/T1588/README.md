# T1588 - Obtain Capabilities

- **Tactic(s):** Resource Development
- **ATT&CK link:** https://attack.mitre.org/techniques/T1588/
- **Platforms:** PRE

## Summary
Adversaries may buy and/or steal capabilities that can be used during targeting.

## Status: guidance only
Obtain Capabilities is a parent technique. This is a Resource Development technique: it happens on infrastructure or accounts the adversary controls, outside your logs.

No sub-technique has a log-based rule either.

## How to detect it
- See the sub-technique READMEs; all sub-techniques are guidance.

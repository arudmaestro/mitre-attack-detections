# T1601 - Modify System Image

- **Tactic(s):** Defense Impairment
- **ATT&CK link:** https://attack.mitre.org/techniques/T1601/
- **Platforms:** Network Devices

## Summary
Adversaries may make changes to the operating system of embedded network devices to weaken defenses and provide new capabilities for themselves.

## Status: guidance only
Modify System Image is a parent technique. Network device techniques run on routers, switches and firewalls; their logs (syslog, AAA, configuration archives) are not data sources of this project yet.

No sub-technique has a log-based rule either.

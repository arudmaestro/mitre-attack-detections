# T1556 - Modify Authentication Process

- **Tactic(s):** Defense Impairment, Persistence, Credential Access
- **ATT&CK link:** https://attack.mitre.org/techniques/T1556/
- **Platforms:** IaaS, Identity Provider, Linux, macOS, Network Devices, Office Suite, SaaS, Windows

## Summary
Adversaries may modify authentication mechanisms and processes to access user credentials or enable otherwise unwarranted access to accounts.

## Status: guidance only
Modify Authentication Process is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1556.004 and T1556.009 are guidance.

# T1558 - Steal or Forge Kerberos Tickets

- **Tactic(s):** Credential Access
- **ATT&CK link:** https://attack.mitre.org/techniques/T1558/
- **Platforms:** Linux, macOS, Windows

## Summary
Adversaries may attempt to subvert Kerberos authentication by stealing or forging Kerberos tickets to enable Pass the Ticket.

## Status: guidance only
Steal or Forge Kerberos Tickets is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; all sub-techniques have rules.

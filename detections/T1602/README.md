# T1602 - Data from Configuration Repository

- **Tactic(s):** Collection
- **ATT&CK link:** https://attack.mitre.org/techniques/T1602/
- **Platforms:** Network Devices

## Summary
Adversaries may collect data related to managed devices from configuration repositories.

## Status: guidance only
Data from Configuration Repository is a parent technique. Configuration repositories are SNMP and device configuration stores.

Detections live in the sub-technique folders.

## How to detect it
- See the sub-technique READMEs; T1602.001 has a rule; T1602.002 is guidance.

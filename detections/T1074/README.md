# T1074 - Data Staged

- **Tactic(s):** Collection
- **ATT&CK link:** https://attack.mitre.org/techniques/T1074/
- **Platforms:** ESXi, IaaS, Linux, macOS, Windows

## Summary
Adversaries may stage collected data in a central location or directory prior to Exfiltration.

## Status: guidance only
Data Staged is a parent technique.

## How to detect it
- See T1074.001 and T1074.002 guidance.

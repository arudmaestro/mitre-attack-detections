# T1606 - Forge Web Credentials

- **Tactic(s):** Credential Access
- **ATT&CK link:** https://attack.mitre.org/techniques/T1606/
- **Platforms:** SaaS, Windows, macOS, Linux, IaaS, Office Suite, Identity Provider

## Summary
Adversaries may forge credential materials that can be used to gain access to web applications or Internet services.

## Status: guidance only
Forge Web Credentials is a parent technique. Forged web credentials are presented to web applications and identity providers.

Detections live in the sub-technique folders.

## How to detect it
- See the sub-technique READMEs; T1606.002 has rules; T1606.001 is guidance.

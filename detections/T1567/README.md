# T1567 - Exfiltration Over Web Service

- **Tactic(s):** Exfiltration
- **ATT&CK link:** https://attack.mitre.org/techniques/T1567/
- **Platforms:** ESXi, Linux, macOS, Office Suite, SaaS, Windows

## Summary
Adversaries may use an existing, legitimate external Web service to exfiltrate data rather than their primary command and control channel.

## Status: guidance only
Exfiltration Over Web Service is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1567.001 is guidance.

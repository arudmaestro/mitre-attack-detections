# T1219 - Remote Access Tools

- **Tactic(s):** Command And Control
- **ATT&CK link:** https://attack.mitre.org/techniques/T1219/
- **Platforms:** Linux, macOS, Windows

## Summary
An adversary may use legitimate remote access tools to establish an interactive command and control channel within a network.

## Status: guidance only
Remote Access Tools is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1219.001 IDE tunnels, T1219.002 remote desktop software); T1219.003 is guidance.

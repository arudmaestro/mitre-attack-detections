# T1102 - Web Service

- **Tactic(s):** Command And Control
- **ATT&CK link:** https://attack.mitre.org/techniques/T1102/
- **Platforms:** ESXi, Linux, macOS, Windows

## Summary
Adversaries may use an existing, legitimate external Web service as a means for relaying data to/from a compromised system.

## Status: guidance only
Web Service C2 is a parent technique.

## How to detect it
- See the T1102 sub-technique guidance.

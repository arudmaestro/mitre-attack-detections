# T1566.004 - Phishing: Spearphishing Voice

- **Tactic(s):** Initial Access
- **ATT&CK link:** https://attack.mitre.org/techniques/T1566/004/
- **Platforms:** Linux, macOS, Windows, Identity Provider

## Summary
Adversaries may use voice communications to ultimately gain access to victim systems.

## Status: guidance only
Voice phishing happens over the phone; the result is a user who runs a remote-access tool or gives away credentials.

## How to detect it
- Detect what follows: remote-access tools installed by users (T1219 rules), MFA push fatigue and sign-ins from new devices, helpdesk password reset procedures with verification.

# T1566 - Phishing

- **Tactic(s):** Initial Access
- **ATT&CK link:** https://attack.mitre.org/techniques/T1566/
- **Platforms:** Identity Provider, Linux, macOS, Office Suite, SaaS, Windows

## Summary
Adversaries may send phishing messages to gain access to victim systems.

## Status: guidance only
Phishing is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1566.001 has a rule; .002 - .004 are guidance.

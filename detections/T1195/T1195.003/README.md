# T1195.003 - Supply Chain Compromise: Compromise Hardware Supply Chain

- **Tactic(s):** Initial Access
- **ATT&CK link:** https://attack.mitre.org/techniques/T1195/003/
- **Platforms:** Linux, macOS, Windows

## Summary
Adversaries may manipulate hardware components in products prior to receipt by a final consumer for the purpose of data or system compromise.

## Status: guidance only
Hardware supply chain compromise (implants, modified firmware) is below the OS.

## How to detect it
- Firmware integrity checks (Secure Boot, measured boot, vendor attestation) and trusted procurement.

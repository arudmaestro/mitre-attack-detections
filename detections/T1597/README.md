# T1597 - Search Closed Sources

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1597/
- **Platforms:** PRE

## Summary
Adversaries may search and gather information about victims from closed (e.g., paid, private, or otherwise not freely available) sources that can be used during targeting.

## Status: guidance only
Search Closed Sources is a parent technique. This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

No sub-technique has a log-based rule either.

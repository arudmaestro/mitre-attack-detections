# T1597.001 - Search Closed Sources: Threat Intel Vendors

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1597/001/
- **Platforms:** PRE

## Summary
Adversaries may search private data from threat intelligence vendors for information that can be used during targeting.

## Status: guidance only
This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

## How to detect it
- Threat intelligence reports can reveal what defenders know; nothing to detect in your environment.

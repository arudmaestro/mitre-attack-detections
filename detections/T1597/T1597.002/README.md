# T1597.002 - Search Closed Sources: Purchase Technical Data

- **Tactic(s):** Reconnaissance
- **ATT&CK link:** https://attack.mitre.org/techniques/T1597/002/
- **Platforms:** PRE

## Summary
Adversaries may purchase technical information about victims that can be used during targeting.

## Status: guidance only
This is a Reconnaissance technique: it uses public sources or the adversary's own systems, so it leaves little or nothing in your logs.

## How to detect it
- Purchased data (leaked databases, access broker listings) is outside your logs; dark-web monitoring services can alert on your domain and IP ranges appearing in such listings.

# T1687 - Exploitation for Defense Impairment

- **Tactic(s):** Defense Impairment
- **ATT&CK link:** https://attack.mitre.org/techniques/T1687/
- **Platforms:** IaaS, Linux, macOS, SaaS, Windows

## Summary
Adversaries may exploit vulnerabilities in security software, infrastructure, or defensive components to degrade, disable, or otherwise continue to impair their ability to prevent, detect, or respond to malicious activity.

## Status: guidance only
Exploitation of security software is a vulnerability in the defensive tool itself; the exploit has no generic signature.

## How to detect it
- Patch security products and appliances quickly; alert when agents crash, stop reporting or downgrade; vendor advisories for exploited flaws in security tools.

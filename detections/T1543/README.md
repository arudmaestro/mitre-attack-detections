# T1543 - Create or Modify System Process

- **Tactic(s):** Persistence, Privilege Escalation
- **ATT&CK link:** https://attack.mitre.org/techniques/T1543/
- **Platforms:** Containers, Linux, macOS, Windows

## Summary
Adversaries may create or modify system-level processes to repeatedly execute malicious payloads as part of persistence.

## Status: guidance only
Create or Modify System Process is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules (T1543.001 - .004); T1543.005 is guidance.

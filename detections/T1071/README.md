# T1071 - Application Layer Protocol

- **Tactic(s):** Command And Control
- **ATT&CK link:** https://attack.mitre.org/techniques/T1071/
- **Platforms:** Linux, macOS, Windows, Network Devices, ESXi

## Summary
Adversaries may communicate using OSI application layer protocols to avoid detection/network filtering by blending in with existing traffic.

## Status: guidance only
Application Layer Protocol C2 is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- See the sub-technique folders (T1071.003 has a rule; the others are guidance).

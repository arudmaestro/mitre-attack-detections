# T1548 - Abuse Elevation Control Mechanism

- **Tactic(s):** Privilege Escalation
- **ATT&CK link:** https://attack.mitre.org/techniques/T1548/
- **Platforms:** Linux, macOS, Windows, IaaS, Office Suite, Identity Provider

## Summary
Adversaries may circumvent mechanisms designed to control privilege elevation to gain higher-level permissions.

## Status: guidance only
Abuse Elevation Control Mechanism is a parent technique.

Detections live in the sub-technique folders.

## How to detect it
- Use the sub-technique rules; T1548.005 is guidance.
